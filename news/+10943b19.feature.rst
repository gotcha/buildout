Speed up repeated buildout runs: sources listed in the ``develop`` option are
no longer reinstalled (``pip install -e``) on every run.  An editable install
does not copy code, so reinstalling is only needed when packaging metadata may
have changed.  A develop egg is now only reinstalled when its ``setup.py``,
``setup.cfg`` or ``pyproject.toml`` is newer than its egg-link, when its
egg-info is missing, or when the develop-eggs directory changed.  Verbose
output tells the two cases apart: ``Making editable install`` now means an
install actually happened, while a kept egg-link is reported as ``Keeping
editable install of ...: its packaging metadata ... is unchanged`` followed
by ``Reusing editable install: ...``.  [gotcha]
