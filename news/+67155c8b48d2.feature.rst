With ``installer = uv``, ambient ``UV_*`` environment variables (``UV_INDEX_URL``, ``UV_DEFAULT_INDEX``, ``UV_EXTRA_INDEX_URL``, ``UV_FIND_LINKS``, ``UV_PRERELEASE``, ``UV_OFFLINE``, ``UV_NO_CACHE``, ``UV_INSECURE_HOST``) no longer leak into resolves: the seam spawns uv with them scrubbed so the buildout configuration alone decides sources, while ``UV_CACHE_DIR`` is kept because it names the store offline resolves serve from.
